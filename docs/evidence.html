Evidence · one artifact, four states

What counted as evidence here.

A model's opinion was never admissible. Every verdict on this site came from a deterministic tool with a version, a scope and a hash, applied to a frozen task.

Scroll to reveal

The substrate

Six frozen tasks, held out and hashed.

BENCH-002 v0.1 is a set of six clean held-out tasks covering the constraint constructs that fail quietly: primary clocks, generated clocks, input and output delays, false paths, multicycle paths, and one adversarial case where a clock is driven from data.

The tasks were hand authored after the prompt freeze, so the prompt could not have been tuned against them. Each task has its own distinct hash, and the benchmark as a whole has its own.

States

Four states of the same artifact.

One candidate file, followed from raw text to an authorized verdict. The same loop, the same authorities and the same contract apply at every state.

01

Initial

The raw proposal, before any checker has seen it. It is stored with its input hash so that the exact text under evaluation is recoverable later, even if the prompt template changes in a future round.

02

Divergence

On task T2 this candidate drew ACCEPT from Ṛta, which owns constraint quality, and REJECT from OpenSTA, which owns timing. Neither was wrong. The constraint set was well formed, and the timing it described genuinely failed, with a negative worst slack of one to two hundredths of a nanosecond.

T1 and T2 are the pilot's own two frozen starting artifacts rather than benchmark task numbers: each is defined by its initial SDC in the frozen pilot manifest. T2's frozen clock, a period of 0.05 nanoseconds, is deliberately unmeetable, which is what lets the timing authority expose a real violation that structural checks cannot see.

The verdicts are recorded as an existence proof that the two authorities answer different questions. They are explicitly not recorded as prevalence evidence: one task, one candidate, one divergence.

03

Bounded revision

The findings were handed back and the artifact was revised against them, inside a bounded number of cycles, with each intermediate artifact hashed. The revision never received the model's own commentary as input, only the normalized evidence.

04

Verification gate

The gate, and only the gate, converted the collected evidence into ACCEPT or REJECT. Both readings were retained, including the divergence, rather than being reconciled into a single summary judgement.

Admissibility

Three tests a piece of evidence had to pass.

Pinned

It came from a tool at a stated version, so a verdict can be re-derived later rather than trusted. Ṛta was held at 1.5.11@3b5c2f2 and did not change through the reviewed gates.

Scoped

It stated how much of the artifact it actually covered. A partial inspection cannot be reported as a verdict on the whole file, and an authority that declines to answer is recorded as insufficient rather than as a rejection.

Reproducible

It travelled with the hash of the input it was computed from, so the reading and the artifact it describes cannot drift apart after the fact.

The full frozen state, including the tasks, run counts and verdicts, is recorded in research/STATE.md.
