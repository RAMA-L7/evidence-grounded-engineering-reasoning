Heterogeneous deterministic authorities for reliable LLM-assisted revision

A language model proposes a timing constraint file. Two deterministic checkers evaluate different properties of that same file. A separate gate, never the model, decides whether the artifact is acceptable. This site reports what the arrangement demonstrated, and what it did not.

Findings

Three things the frozen runs support.

01

Two correct answers

On task T2 the same candidate artifact drew ACCEPT from Ṛta and REJECT from OpenSTA. Both verdicts were correct in their own property: the constraint set was structurally sound while the timing genuinely failed. One observation, honestly labelled as one observation, is enough to refute Oracle interchangeability.

02

Bounded, not collapsed

Every checker's findings were normalised into one common evidence contract rather than flattened into a single score. Revision stayed traceable and evidence bound, and the single checker baselines suppressed the divergence instead of preserving it.

03

The gate is separate

VerificationGate is the only component permitted to say ACCEPT or REJECT. The proposal never grades itself, evaluation authorities never author, and the import graph contains no circular dependencies. Authority separation across four artifact states.

How it runs

Three authorities, never collapsed into one.

The model proposes. Two deterministic checkers evaluate different properties of the same artifact and report through one typed contract. Only the gate authorises. The five phases are described in full on the method page.
