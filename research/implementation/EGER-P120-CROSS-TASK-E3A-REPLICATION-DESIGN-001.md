# EGER-P120 — Cross-Task E3a Replication Design

## Research Question

Does the broader-task-objective manipulation (E3a) that produced 10/10 adherence on BENCH2-001 in DIAGNOSTIC-006 replicate across other error-bearing BENCH-002 tasks?

---

## Motivation

DIAGNOSTIC-006 E3a produced 10/10 adherence on BENCH2-001, but n=10 on one task is insufficient to establish a general task-framing effect. P119 recommended cross-task replication as the next research gate.

---

## Tasks

| Task | Design Context | Original Objective |
|------|---------------|-------------------|
| BENCH2-002 | Module top with clk, clk_div2. clk is primary 10ns, clk_div2 is generated by dividing clk by 2 at pin div_reg/Q. | Generate SDC with primary clock and correctly constrained generated clock. |
| BENCH2-004 | Module top with clk 10ns, config path from cfg_reg to data_reg is timing exception (false path) by design. | Generate SDC that correctly declares the false path without over-constraining. |
| BENCH2-005 | Pipelined path from pipe_reg1 to pipe_reg2 requires 2 cycles (setup multicycle 2). | Generate SDC with correct multicycle exception. |

These are the three error-bearing tasks identified in P092. BENCH2-003 and BENCH2-006 are excluded (already correct or different failure mode).

---

## Conditions

### BASE

For each task, use:
- Same task design context
- Same initial SDC (the existing BENCH-002 initial candidate for that task)
- Same original task objective
- Full structured EvidenceArtifact feedback
- MODEL-005

### E3a

For each task, use:
- Same task design context
- Same initial SDC (identical to BASE)
- **Broader task objective** (replacing the original)
- Full structured EvidenceArtifact feedback
- MODEL-005

### E3a Objective Template

The broader objective used in DIAGNOSTIC-006 E3a was:

> "Generate a complete, production-quality SDC for this design. Include all required timing constraints: clock definitions, I/O delays, and any applicable exceptions."

For cross-task replication, adapt the template per task while preserving the "complete, production-quality" framing:

| Task | BASE Objective | E3a Objective |
|------|---------------|---------------|
| BENCH2-002 | Generate SDC with primary clock and correctly constrained generated clock. | Generate a complete, production-quality SDC for this design. Include all required timing constraints: clock definitions, generated clocks, and any applicable exceptions. |
| BENCH2-004 | Generate SDC that correctly declares the false path without over-constraining. | Generate a complete, production-quality SDC for this design. Include all required timing constraints: clock definitions, timing exceptions, and any applicable false paths. |
| BENCH2-005 | Generate SDC with correct multicycle exception. | Generate a complete, production-quality SDC for this design. Include all required timing constraints: clock definitions, multicycle exceptions, and any applicable constraints. |

**Critical:** The E3a objective must mention the specific constraint type relevant to the task (generated clock, false path, multicycle) to remain a fair comparison. The manipulation is "complete, production-quality" framing, not removing task-specific information.

For each task:

### Cross-Task Replication

## Statistical Analysis Plan

For each task × condition:
- completed n
- adherent k
- adherence rate k/n
- 95% Clopper-Pearson CI

Within-task difference:
- E3a rate − BASE rate (percentage points)

### Interpretation Rules

| Pattern | Classification |
|---------|---------------|
| E3a > BASE on all 3 tasks | **Strong replication signal** |
| E3a > BASE on 2/3 tasks | **Partial replication** |
| E3a ≤ BASE on all tasks | **No replication** |
| E3a < BASE on multiple tasks | **Unexpected result** |

### What We Will NOT Claim

- "Task framing is proven to be the mechanism"
- Statistical significance from n=10 per cell
- Generalization beyond MODEL-005 + BENCH-002
- Causation beyond the controlled manipulation

## Limitations

1. n=10 per cell — CIs will be wide
2. E3a objective adaptation per task introduces slight variation
3. Initial SDCs differ across tasks (by design — they're different tasks)
4. One model only — results may not generalize
5. Cannot distinguish task-framing effect from objective-length effect
6. Base-rate variability (P119) means BASE comparisons are uncertain
