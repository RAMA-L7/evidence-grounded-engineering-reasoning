## 1. Executive Summary

This document designs a controlled experiment to answer RQ-4: **Does deterministic structured evidence feedback cause an improvement in engineering proposal correctness?**

The experiment uses MODEL-004 (nemotron-3-ultra-free) in BOTH control and treatment conditions. Only the feedback treatment varies. The measurement layer (P059/P060) is now adequate for this comparison.

## 3. Causal Estimand

For each benchmark task *t*:

```
correctness_outcome(t, treatment) - correctness_outcome(t, control)
```

Where:
- `treatment` = structured EvidenceArtifact feedback
- `control` = no feedback
- `correctness_outcome` = error-count delta (pre-registered metric)

**Population-level inference is NOT claimed.** The estimand is specific to the BENCH-002 benchmark tasks under MODEL-004.

---

## 4. Experimental Unit

**Task/run pair.** Each benchmark task produces one paired observation (control, treatment).

With 6 tasks, the experiment produces up to 6 paired observations.

---

## 5. Control Condition

```
Task context + objective + constraints
    ↓
MODEL-004 Call 1 → initial candidate SDC
    ↓
Oracle 1 (with metadata) → initial evidence
    ↓
(no feedback to model)
    ↓
MODEL-004 Call 2 → revised candidate SDC
    ↓
Oracle 2 (with metadata) → final evidence
```

**The model receives NO structured feedback between Call 1 and Call 2.**

The control Call 2 prompt contains only:
- task context
- objective
- required output format
- initial candidate

It does NOT receive:
- structured EvidenceArtifact
- design metadata
- evaluator answers
- hidden benchmark info

---

## 6. Treatment Condition

```
Task context + objective + constraints
    ↓
MODEL-004 Call 1 → initial candidate SDC
    ↓
Oracle 1 (with metadata) → initial evidence
    ↓
deterministic structured EvidenceArtifact feedback
    ↓
MODEL-004 Call 2 → revised candidate SDC
    ↓
Oracle 2 (with metadata) → final evidence
```

**The model receives structured EvidenceArtifact feedback between Call 1 and Call 2.**

The treatment Call 2 prompt contains:
- task context
- objective
- required output format
- initial candidate
- deterministic structured EvidenceArtifact

---

## 7. Paired Design

For each task *t*:

```
initial_candidate(t)  ← IDENTICAL in both branches
    │
    ├── CONTROL: Call 2 without feedback → final_control(t)
    │
    └── TREATMENT: Call 2 with feedback → final_treatment(t)
```

The initial candidate is held constant. The model generates two independent revisions.

## 15. Primary Outcome (Pre-Registered)

**Error-count delta:**

```
delta_error(t) = error_count(final(t)) - error_count(initial(t))
```

Where `error_count` counts only ERROR-severity findings (SDC-005, SDC-006, SDC-007).

### Interpretation

| delta_error | Meaning |
|-------------|---------|
| < 0 | Improvement (fewer errors) |
| = 0 | No change |
| > 0 | Regression (more errors) |

### Primary Comparison

```
treatment_effect(t) = delta_error_treatment(t) - delta_error_control(t)
```

If treatment_effect < 0 → treatment improved correctness more than control.

## 19. Provider-Failure Policy

| Rate limit | Task = MISSING DATA | No retry |
| Timeout | Task = MISSING DATA | No retry |

Maximum per task: 2 model calls, 2 oracle calls.
